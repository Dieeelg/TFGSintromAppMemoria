\subsection{\textit{ /centros/buscar}}

A procura normaliza os nomes, calcula a súa similitude e só acepta coincidencias cunha puntuación igual ou superior a 0,45. A carga do ficheiro emprégase cunha caché dunha única entrada para non analizar de novo o KML en cada petición.


\begin{lstlisting}[language=Python,
    caption={Normalización e procura aproximada dun centro sanitario.},
    label={lst:busqueda-centros}]
def _normalizar(texto: str) -> str:
    texto = unicodedata.normalize("NFKD", texto)
    texto = texto.encode("ascii", "ignore").decode()
    texto = texto.upper()
    texto = re.sub(
        r"\bC\s*\.?\s*S\s*\.?\b", "CENTRO SAUDE", texto
    )
    texto = texto.replace(
        "CENTRO DE SAUDE", "CENTRO SAUDE"
    )
    return re.sub(r"[^A-Z0-9]+", " ", texto).strip()

@lru_cache(maxsize=1)
def _cargar_centros() -> list[dict[str, str | None]]:
    raiz = ET.parse(KML_PATH).getroot()
    centros = []
    for marca in raiz.findall(".//kml:Placemark", KML_NS):
        nome = marca.findtext(
            "kml:name", default="", namespaces=KML_NS
        ).strip()
        descripcion = marca.findtext(
            "kml:description", default="", namespaces=KML_NS
        )
        campos = _campos_descripcion(descripcion)
        if nome and campos.get("TELEFONO"):
            centros.append({
                "nome": campos.get("NOMBRE") or nome,
                "nome_normalizado": _normalizar(
                    campos.get("NOMBRE") or nome
                ),
                "telefono": campos.get("TELEFONO"),
                "enderezo": campos.get("DIRECCION"),
                "concello": campos.get("CONCELLO"),
            })
    return centros

consulta = _normalizar(nome)
for centro in _cargar_centros():
    nome_centro = str(centro["nome_normalizado"])
    coincidencia = SequenceMatcher(
        None, consulta, nome_centro
    ).ratio()
    if consulta in nome_centro or nome_centro in consulta:
        coincidencia += 1
    candidatos.append((coincidencia, centro))

puntuacion, centro = max(candidatos, key=lambda x: x[0])
if puntuacion < 0.45:
    raise HTTPException(status_code=404)
\end{lstlisting}

\subsection{Persistencia e conservación do seguimento}

SQLite separa a pauta activa, a cabeceira, o histórico e os datos das persoas supervisadas. A información máis importante para o seguimento dunha toma
mantense na táboa \texttt{pautas}.

Para distinguir unha reimportación dunha pauta nova calcúlase un identificador determinista. Os textos normalízanse, o calendario ordénase por data e
concaténanse os datos clínicos que definen o tratamento. Non se inclúen o estado, a hora de confirmación nin a desviación, xa que son datos de seguimento que deben conservarse. O identificador non é un valor aleatorio nin un resumo criptográfico.

\begin{lstlisting}[
    caption={Cálculo do identificador dunha folla.},
    label={lst:identificador-documento}]
String _identificadorDocumento(AnaliseModel analise) {
  String limpar(String? valor) =>
      (valor ?? '').trim().toUpperCase();
  final calendario = [...analise.calendario]
    ..sort((a, b) => a.data.compareTo(b.data));

  return [
    limpar(analise.cabeceira.dataInforme),
    limpar(analise.cabeceira.proximaVisita),
    limpar(analise.cabeceira.centro),
    limpar(analise.cabeceira.farmaco),
    ...calendario.map(
      (dia) =>
          '${dia.data}|${limpar(dia.dose)}|'
          '${limpar(dia.accion)}',
    ),
  ].join('::');
}
\end{lstlisting}

  await _algoritmo.newSecretKey()
).extractBytes();
final id = base64UrlEncode(
  idBytes.sublist(0, 16),
).replaceAll('=', '');

final anterior = await _storage.read(
  key: _storagePendenteActual,
);
if (anterior != null && anterior != id) {
  await _storage.delete(key: '$_prefixoPendente$anterior');
}
await _storage.write(key: _storagePendenteActual, value: id);
await _storage.write(
  key: '$_prefixoPendente$id',
  value: claveBase64,
);

return jsonEncode({
  'version': _versionProtocolo,
  'vinculacionId': id,
  'uidPaciente': uidPaciente,
  'tokenPaciente': tokenPaciente,
  'clave': claveBase64,
});
\end{lstlisting}

Despois da vinculación, cada envío emprega a clave permanente e un
\gls{nonce} novo. O identificador e o tipo de aviso incorpóranse como datos
autenticados, polo que unha modificación do contido ou do contexto provoca o
rexeitamento da mensaxe.

\begin{lstlisting}[
    caption={Cifrado e creación dunha mensaxe P2P.},
    label={lst:cifrado-p2p}]
final nonce = _algoritmo.newNonce();
final caixa = await _algoritmo.encrypt(
  utf8.encode(payload),
  secretKey: SecretKey(
    base64Decode(vinculacion.claveBase64),
  ),
  nonce: nonce,
  aad: utf8.encode(
    'sintrom-p2p-v$_versionProtocolo|'
    '${vinculacion.id}|$tipoAviso',
  ),
);

return jsonEncode({
  'version': _versionProtocolo,
  'vinculacionId': vinculacion.id,
  'nonce': base64Encode(caixa.nonce),
  'datos': base64Encode(caixa.cipherText),
  'mac': base64Encode(caixa.mac.bytes),
});
\end{lstlisting}

\subsection{Fragmentación dunha folla completa}

As follas completas divídense en fragmentos de ata 2200 caracteres para non
superar o tamaño adecuado dunha mensaxe de FCM. Cada parte leva un identificador
común, a súa posición e o número total de fragmentos.

\begin{lstlisting}[
    caption={División e envío dunha folla en fragmentos cifrados.},
    label={lst:fragmentacion}]
final id = DateTime.now()
    .microsecondsSinceEpoch
    .toString();
const tamanho = 2200;
final total = (json.length / tamanho).ceil();

for (var i = 0; i < total; i++) {
  final fin = (i + 1) * tamanho > json.length
      ? json.length
      : (i + 1) * tamanho;
  await _enviarCifrado(
    vinculacion: vinculacion,
    payload: jsonEncode({
      'id': id,
      'indice': i,
      'total': total,
      'datos': json.substring(i * tamanho, fin),
    }),
    tipoAviso: 'INFORME_FRAGMENTO',
  );
}
\end{lstlisting}

O receptor garda cada parte temporalmente e só reconstrúe o \gls{json} cando
dispón de todos os índices. Despois crea o modelo, garda a pauta, recalcula os
recordatorios e elimina os fragmentos. Así non se incorpora unha folla
incompleta cando falta algunha mensaxe.
