\section{Estrutura interna da solución}
\label{app:estrutura-interna}

O código do cliente móbil distribúese en directorios segundo a
responsabilidade de cada elemento:

\begin{verbatim}
client/lib/
|-- componentes/
|-- modelos/
|-- modelos_vista/
|   `-- autenticacion/
|-- nucleo/
|-- recursos/
|-- servizos/
|-- views/
|   `-- camara/
`-- main.dart
\end{verbatim}

Os directorios \textit{views}, \textit{modelos\_vista} e \textit{modelos}
correspóndense respectivamente coas capas View, ViewModel e Model do patrón
MVVM. O directorio \textit{servizos} contén as operacións de acceso á API,
persistencia, notificacións, cifrado e sincronización, mentres que
\textit{componentes} agrupa elementos visuais reutilizables.

A API presenta a seguinte organización:

\begin{verbatim}
server/app/
|-- data/
|-- internal/
|-- routers/
|-- schemas/
|-- dependencies.py
`-- main.py
\end{verbatim}

\textit{main.py} crea a aplicación FastAPI e rexistra os routers.
\textit{routers} define os endpoints, \textit{internal} contén a lóxica de
procesamento, \textit{schemas} define os modelos de intercambio e
\textit{dependencies.py} inicializa o acceso aos servizos externos.

\section{Comunicación entre dispositivos}
\label{app:comunicacion}

A vinculación inicial permite establecer unha relación entre un paciente e
un supervisor. O dispositivo do paciente xera un código QR que contén un
identificador da vinculación, o identificador do paciente, o token de Firebase
Cloud Messaging e unha clave temporal.

O supervisor le este código e completa o proceso de vinculación. A partir
dese momento mantense unha clave asociada á relación entre ambos dispositivos.
As claves gárdanse mediante \textit{Secure Storage}.

Para as comunicacións posteriores emprégase AES-GCM con claves de 256 bits.
Cada mensaxe cifrada contén, como mínimo, a versión do protocolo, o
identificador da vinculación, o \textit{nonce}, os datos cifrados e o código
de autenticación da mensaxe. A API recibe este sobre cifrado e envíao ao
dispositivo destinatario mediante Firebase Cloud Messaging.
